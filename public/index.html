iroh-mic

Static webapp that dials peers by public key with iroh and streams a live microphone feed from one browser to another. No backend, no signaling server — only iroh's discovery and relay.

1. Your endpoint id

Share this with the other device, or open a second tab and paste it there.

…

Or send this page's link with the id pre-filled: open connect link

2. Start your audio

Put on headphones. To hear the other side, press listen. To send your own audio, use the microphone or generate a 440 Hz test tone.

3. Connect to a peer

Connections resume automatically when you come back to this tab; the endpoint id is stable for this tab so the peer can reconnect too.
